阶段10：所有单例bean初始化完成后阶段 ====================================================================================================== 所有单例bean实例化完成之后，spring会回调下面这个接口： public interface SmartInitializingSingleton { void afterSingletonsInstantiated(); } 调用逻辑在下面这个方法中： /** * 确保所有非lazy的单例都被实例化，同时考虑到FactoryBeans。如果需要，通常在工厂设置结束时调用。 */ org.springframework.beans.factory.support.DefaultListableBeanFactory#preInstantiateSingletons 这个方法内部会先触发所有非延迟加载的单例bean初始化，然后从容器中找到类型是SmartInitializingSingleton的bean，调用他们的afterSingletonsInstantiated方法。 有兴趣的可以去看一下带有ApplicationContext的容器，内部最终都会调用上面这个方法触发所有单例bean的初始化。 来个2个案例演示一下SmartInitializingSingleton的使用。 案例1：ApplicationContext自动回调SmartInitializingSingleton接口： demo10：SmartInitializingSingletonTest 案例2：通过api的方式让DefaultListableBeanFactory去回调SmartInitializingSingleton： demo10：SmartInitializingSingletonTest1
