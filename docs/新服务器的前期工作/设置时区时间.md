## 修改系统时区和时间，并开启时间同步服务NTP

查看时区和时间命令：timedatectl
结果：

```shell
[root@CentOS-1 ~]# timedatectl
      Local time: 日 2024-03-24 00:21:30 CST
  Universal time: 六 2024-03-23 16:21:30 UTC
        RTC time: 六 2024-03-23 16:21:30
       Time zone: Asia/Shanghai (CST, +0800)
     NTP enabled: n/a
NTP synchronized: no
 RTC in local TZ: no
      DST active: n/a

```

上面的信息说明了使用的是上海时区，时区和时间都是对的，应该是在安装centos镜像的时候就选择了上海时区。
并显示没有开启NTP（网络时间协议：使计算机时间同步化的协议）

查看NTP状态：
systemctl status ntpd
结果显示：Unit ntp.service could not be found.
说明没有安装ntp客户端或工具包。

开启NTP需要先安装NTP客户端：
yum install ntp
再查看ntp状态就会提示ntp服务已经有了但是是不活跃状态（没有启动服务）。
然后启动服务就行了：
systemctl start ntpd

修改ntp配置文件：
vim /etc/ntp.conf
这里面可以配置远程时间的时间源服务器地址，比如阿里云的，或国家授时的。
具体的配置细节后面研究。
修改配置后重启：
systemctl restart ntpd
重启后要再检查timedatectl，看看到底有没有设置正确。这里先不研究。

检查同步状态：
ntpq -p

设置开机自启：
systemctl enable ntpd

如果使用NTP机制，自然就不用手动设置时间了。
