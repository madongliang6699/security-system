##下面的内容是基于CentOS 7系统

## 安装vim
yum install vim

## 安装htop
首先在CentOS 7上启用epel版本：
yum -y install epel-release
安装CentOS htop：
yum -y install htop

## 安装jdk
查询可安装的jdk版本：
yum search java|grep jdk
安装指定的版本：
yum install java-1.8.0-openjdk-src.x86_64


## 安装git 
如果需要的话就安装，比如Jenkins底层需要使用git拉取代码，Jenkins服务器上要安装git。  
yum install git -y

## 安装maven
安装maven前需要先安装jdk

yum install maven -y

## 安装 lsof
yum update（这个不要随意执行，不然会更新很久已有的软件）
yum install -y lsof
lsof -v
 
## 安装 man 页面 中文翻译
yum install man-pages-zh-CN.noarch  
安装完之后，如果该命令的介绍有中文翻译页面就显示中文的，否则显示英文的。有点命令好像中英文都没有，提示无该命令手册。

## 安装tree， 树形展示目录
yum install tree
