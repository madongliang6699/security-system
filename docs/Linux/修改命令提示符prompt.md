## 命令提示符 prompt

登录Linux后，默认的系统命令提示符毫无没有个性，无法明显辨别生产和测试环境，而导致误操作。
可以通过修改PS1变量实现个性的提示符格式，避免这种低级错误。

范例：默认的提示符
#CentOS默认提示符：
[root@localhost ~]#
管理员是 #
普通用户是 $

显示提示符格式：

~~~shell
[root@centos8 ~]#echo $PS1
\[\e[1;35m\][\u@\h \W]\$\[\e[0m\]
~~~

可以修改提示符PS1为以下格式：
PS1="\[\e[1;5;41;33m\][\u@\h \W]\\$\[\e[0m\]"
或
PS1="\[\e[1;32m\][\t \[\e[1;33m\]\u\[\e[35m\]@\h\[\e[1;31m\] \W\[\e[1;32m\]]\[\e[0m\]\\$"

提示符格式说明：

~~~
\e 控制符\033
\u 当前用户
\h 主机名简称
\H 主机名
\w 当前工作目录
\W 当前工作目录基名
\t 24小时时间格式
\T 12小时时间格式
! 命令历史数
# 开机后命令历史数
~~~

范例：在CentOS系统实现持久保存提示符格式:

~~~shell
[root@centos8 ~]# echo 'PS1="\[\e[1;5;41;33m\][\u@\h \W]\\$\[\e[0m\]"' > /etc/profile.d/env.sh
~~~

就是把设计好的PS1的值配置到/etc/profile.d/env.sh中。就可以实现永久设置个性化提示符，下次登录也默认是设置好的样式。

env.sh只是随意起名了一个叫env的sh文件，放进了这个文件中，叫什么名无所谓我，应该是只要是这个/etc/profile.d/文件夹下的登录后都会
自动设置成环境变量，而PS1就是环境变量，进而实现的永久更换提示符样式吧。
