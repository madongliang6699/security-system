## cd 
cd ~或cd	回到自己的家目录

cd ..	回到当前目录的上一级目录

## mkdir：创建一个新的目录
1）基本语法:
mkdir [选项] 要创建的目录

2）选项说明: -p 创建多层目录.  
递归创建多级目录需要加-p选项，否则，父目录不存在时会报错:
~~~shell
[root@testx ~]# mkdir a/b/c/d
mkdir: 无法创建目录"a/b/c/d": 没有那个文件或目录
[root@testx ~]# mkdir -p a/b/c/d
~~~

## cp：复制文件或目录
cp [选项] 源文件 目标文件   只能复制文件，不能复制文件夹。

-r	递归复制整个文件夹, 也能只复制指定的文件。

说明：cp -r a b 该命令，如果b文件夹已经存在，就把a文件夹和下面的文件都复制到b下面，此时b下面有个a文件夹。如果b文件夹不存在，就只是复制出一个和a一样的文件夹和内部文件，名字改成b而已，此时b下面没有a文件夹。

经验技巧：
强制覆盖不提示的方法：\cp，因为cp命令是cp -i的别名，
-i选项的作用是当出现文件覆盖的时候需要提示用户选择是否覆盖，这也是为了安全起见，
而\命令可以按照命令原始的方式运行。

~~~shell
#案例
#（1）复制文件
[root@testx ~]# touch 1.txt
[root@testx ~]# cp 1.txt /tmp/

#（2）递归复制整个文件夹
[root@testx ~]# mkdir a
[root@testx ~]# touch a/1.txt
[root@testx ~]# touch a/2.txt
[root@testx ~]# ls a
1.txt  2.txt
[root@testx ~]# cp -r a b
[root@testx ~]# ls b
1.txt  2.txt

#（3）\cp：复制，覆盖不提示
[root@testx ~]# touch 1.txt
[root@testx ~]# cp 1.txt /tmp/
[root@testx ~]# cp 1.txt /tmp/
cp: 是否覆盖"/tmp/1.txt"? y
[root@testx ~]# \cp 1.txt /tmp/
~~~

## rm：删除文件或目录
rm [选项] 文件1 文件2 [文件N...]

-r	递归删除目录中所有内容
-f	强制执行删除操作，不会提示用户是否确认删除
-v	显示命令的详细执行过程

 #### *通配符删除：
rm -rf a*  递归删除当前目录的所有a开头的目录和文件。

rm -rf /*：删除根目录下的所有东西。删库跑路。 此命令慎用，否则永无回头之日。如果是普通用户，没关系，没权限删除其他用户的文件。

## cat：查看文件内容
cat [选项] 要查看的文件。 -n	显示所有行的行号，也包含空行。 -A 显示出隐藏的特殊字符，对排除文件或脚本的错误字符导致的报错有用

## more：文件内容分屏查看器

适合查看内容超过一个屏幕的文件，支持上下翻页查看文件内容。

more命令是一个基于VI编辑器的文本过滤器，它以全屏幕的方式按页显示文本文件的内容，more命令中内置了若干快捷键，详见操作说明。

1）基本语法：
more 要查看的文件

2）操作说明：  
操作	说明
空白键(space)	向下翻一页
b	向上翻一页
Enter	向下翻【一行】
q	代表立刻离开more，不再显示该文件内容
=	输出当前行的行号
:f	输出文件名和当前行的行号


## less：分屏显示文件内容
less指令用来分屏查看文件内容，它的功能与more指令类似，但是比more指令更加强大，
支持各种显示终端，less指令在显示文件内容时，并不是一次将整个文件加载之后才显示，
而是根据显示需要去加载的内容，对于显示大型文件具有较高的效率。

空白键（space）	向下翻动一页
[pagedown] 或 f	上下翻动一页
[pageup] 或 b	向上翻动一页
/字符串	向下搜寻【字符串】的功能；n：向下查找；N：向上查找
?字符串	向上搜索【字符串】的功能，n：向上查找，N：向下查找
q	离开less这个程序

| 语法	               | 说明                               |
|-------------------|----------------------------------|
| ls -l > 目标文件      | 	将ls -l命令的结果写入到目标文件中（会覆盖目标文件内容）  |

## ln：创建软连接
软连接也称为符号链接，类似于windows里的快捷方式，有自己的数据块，主要存放了连接其他文件的路径。

给源文件创建一个软连接 ： ln -s [源文件或目录] [软连接名称]

删除软连接：rm -rf 软连接名称，而不是 rm -rf 软连接名称/  
如果使用rm -rf 软连接名/ 删除，会把软连接对应的真实目录下内容删除。  
查询：通过ll就可以查看，列表属性第1位是1，尾部会有位置指向。

## history 和 ！
history可以查看已执行过的历史命令，返回的结果：命令编号 命令  
history n ：查看最近n条命令。  
history -c：清除命令历史记录

!命令编号，可以执行对应编号的命令

~~~shell
[root@testx ~]# history
    1  pwd
    2  exit
    3  pwd
    4  ll
    5  mkdir 123
    6  ll
    7  rm 123
    8  rm -rf 123
~~~

再执行一遍5对应的命令：
~~~shell
[root@testx ~]# !5
mkdir 123
~~~
