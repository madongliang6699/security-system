
## 查看mysql的参数

SHOW GLOBAL VARIABLES; 全局参数
SHOW SESSION VARIABLES; 或者简写 SHOW VARIABLES; 查看会话参数（适用于当前连接）
SHOW GLOBAL VARIABLES LIKE '%sort%'; 查看特定的参数，如果不写GLOBAL默认查询当前会话的参数。

#### 还可以使用@@前缀来查看或设置特定系统变量的值
SELECT @@global.max_connections;  全局max_connections参数的当前值。
SELECT @@session.max_connections; 或者简写SELECT @@max_connections;  会话级别的max_connections参数值

## 设置参数的值
SET GLOBAL 参数名 = 参数值; 设置全局参数，注意：重启mysql服务后，命令行中配置的值将会失效！可以在配置文件中配置永久生效。

有些设置数值大小的参数，比如设置数据传输总包大小的参数，用命令行设置的话，单位只能是字节（Byte）（1kb=1024字节），

请注意，更改全局参数需要SUPER权限，而对于会话级别的更改则不需要特殊权限。
