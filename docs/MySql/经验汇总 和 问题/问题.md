## 问题2.mysql参数修改后,服务要重启才能在java程序中生效吗
修改mysql配置后,是不是一定要重启服务,好像是因为java程序数据库连接池一旦连接之后, 就缓存了一份数据量库的配置,
程序每次连接数据库都是使用已经缓存的配置参数,此时如果修改了mysql的参数,比如查询页缓存内存大小改大了一些, 
这个时候, 只能重启服务,才能拿到最新的配置的参数. 用最新的参数连接数据库.

## show global STATUS 和 show variables的区别和用途
以及这两个命令,平时在解决什么问题的时候,需要用,怎么结合着用来监控msyql的健康状态, 进而优化msyql的参数配置.
Status查出来的是状态值,都是以大写英文字母开头的名称, variables查出来的是静态的参数,是配置项,不会随着mysql服务的运行而改变. 是以小写字母开头的名称.
通过监控status状态,判断msyql异常点,为variables参数优化提供支持.
