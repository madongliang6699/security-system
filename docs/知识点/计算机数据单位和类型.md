
## 单位转换
bit 简写为 b， 是最小的数据单位，表示二进制的 0 或 1。1bit可以表示两种状态（0 或 1）。
Byte（字节，通常缩写为 B）是8个bit组成的字节，1 Byte = 8 bits，是计算机处理数据的基本单位。

而 byte 是在编程语言中通常指的是一种数据类型。是基本数据类型，表示 8-bit 有符号整数，
也就是说，编程语言中的1个byte数据类型对应着计算机数据单位的1个Byte。
以 Java 为例，byte 是 Java 中的基本数据类型之一，表示一个 8-bit 有符号整数。在 Java 中，byte 的取值范围是从 -128 到 127。

而 编程语言中的 Byte 是byte对应的包装类，通常用着表示byte对应的对象，提供了更多的操作，并允许与 Java 的集合类一起使用。因为byte类型不能new对象，不能与集合结合使用。
