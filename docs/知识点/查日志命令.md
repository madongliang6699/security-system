

### 【第一种：头部尾部查询、实时监控查询 】
>tail翻译：尾部，尾巴（名），跟踪尾随（动）。因为tail有尾随的意思，所以tail命令有做实时监控展示内容的功能。
- head -10 app.log 【显示头部10行】
- tail -10 app.log 【显示尾部10行】
- tail -f app.log　【实时监控app.log文件动态。)
- tail -200f app.log  【显示最后200行，并继续实时监控。相当于tail -200 -f app.log，相当于tail -n 200 -f app.log)
- tail -n +5 app.log　【从第5行开始显示文件)



### 【第二种：关键字查询】
>grep查询默认区分大小写，加 -i 参数后不区分大小写，加-n参数显示行号。
> 
>注意：关键词如果是 - 或者 ) 这种特殊符号的时候，要用\转义，比如： grep -E "\-\-" xxx.log  查询关键词--的日志行。

- 查询文件中包含关键字的所有行： grep  xxx(关键字)   xxx.log(日志文件)
- 查询文件中包含关键字的所有行，再进行二次或多次过滤： grep  xxx(关键字)   xxx.log(日志文件)   |  grep xxx(关键字)
- 查询多个文件中包含关键字的所有行： grep  xxx(关键字)   xxx1.log(日志文件)   xxx2.log(日志文件)
- 显示文件里匹配xxx字串那行以及上下5行： grep -C 5  xxx  xx.log
- 显示文件里匹配xxx字串那行以及前5行： grep -B 5  xxx  xx.log
- 显示文件里匹配xxx字串那行以及后5行： grep -A 5  xxx  xx.log
- 查询满足任意条件（word1、word2和word3之一）的行： grep -E "word1|word2|word3" xxx.log
- 必须同时满足三个条件（word1、word2和word3）的行： grep word1 file.txt | grep word2 | grep word3
- 只展示查询到的最后10行： grep  xxx  xx.log | tail -10
- 只展示查询到的最初10行： grep  xxx  xx.log | head -10





### 【第三种：vim（vi）进入文件查询】
进入后先输入冒号：再输入“/关键字”按回车查询，按n或者N进行下一个或上一个查询。
ctrl+d: 下翻半屏。
ctrl+u: 上翻半屏。
ctrl+e: 向下滚动一行。
ctrl+y: 向上滚动一行。
ctrl+o回到搜索的地方。
搜索到关键字后可以按i或者s进行修改。按Esc，冒号： wq! 保存退出；q! 不保存退出；




### 【第四种：快速浏览文件： more xx.log】
回车键向下一行，空格键向下一屏。Ctrl+b向上一屏。
= 显示当前行号
:f 显示文件名和当前行号
v 调用vim编辑器直接编辑当前位置，这个很有用（可以快速浏览一个配置文件，
找到要修改的地方直接按v调用vim编辑并保存，注意编辑保存后退出vim回到more后，
看到的是没编辑之前的内容，退出more再进入看到的就是编辑后的内容了）
q 退出
!命令  调用shell命令
