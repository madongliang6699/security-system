

### 1）镜像命令
镜像：相当于应用的安装包，在Docker部署的任何应用都需要先构建成为镜像  

- docker search 镜像名称 搜索镜像  
- docker pull 镜像名称 拉取镜像
- docker images 查看本地所有镜像
- docker rmi -f 镜像名称 删除镜像 
- docker pull openjdk:8-jdk-alpine


### 2）容器命令
容器：容器是由镜像创建而来。容器是Docker运行应用的载体，每个应用都分别运行在Docker的每个容器中。

- docker run -i 镜像名称:标签 运行容器（默认是前台运行）  
  常用的参数：
  - -i：保持容器运行。通过和-t同时使用。加入-it这两个参数以后，容器创建后会自动进入容器中，退出容器后，容器会自动关闭。
  - -t：为容器重新分配一个伪输入终端（就是容器内部的命令行），通常和-i同时使用。-it：创建的容器一般称为交互式容器,通过exit命令退出容器后，容器将会停止运行。
  - -d：--detach 后台守方式运行（守护式）,容器不会占用当前终端的控制权，而是返回一个容器的ID。创建一个容器在后台运行，需要使用docker exec 进入容器,退出容器后，容器仍然保持运行。
  - --name：给容器添加名称
  - -p：--publish,用于将容器的端口映射到主机的端口:docker run -p 8080:80 nginx,将Nginx容器的80端口映射到主机的8080端口
  - -v：可以将主机的数据卷(目录或文件夹)挂载到容器中，使得容器可以访问主机中的文件:docker run -v /host/data:/container/data nginx 将主机中的“/host/data”目录挂载到Nginx容器中的“/container/data”目录下。

> 注意：docker create 命令只创建容器不启动容器，容器的状态只是created不是运行中，docker run 是创建后直接运行。created的容器需要用docker start/run 启动容器。 
 这里需要注意的是：docker create -it 的方式创建的容器，后期在start启动之后立马进入容器，退出后立马停止容器的运行（和上面的 docker run -it 一个道理），因此，这里可能会让人疑惑为什么容器总是停止运行了。
 
> 后面的/bin/bash的作用是表示载入容器后运行bash ,docker中必须要保持一个进程的运行，要不然整个容器启动后就会马上kill itself，这个/bin/bash就表示启动容器后启动bash。

> -v参数的数据卷概念：数据卷:
• 数据卷是宿主机中的一个目录或文件
• 当容器目录和数据卷目录绑定后，对方的修改会立即同步
• 一个数据卷可以被多个容器同时挂载
• 一个容器也可以被挂载多个数据卷

> 数据卷作用:
• 容器数据持久化
• 外部机器和容器间接通信
• 容器之间数据交换

>数据卷挂载注意事项：
1.目录必须是绝对路径
2.如果目录不存在，会自动创建
3.可以挂载多个数据卷,即多写几个-v就行了
4.注：如果容器删除了,但是数据卷并不会被删除,它仍然存在于宿主机目录里

> 其他参数：https://cloud.tencent.com/developer/article/2246184

- docker ps 查看容器，默认查看运行中的容器   
    常用参数：
  - -a 会列出当前服务器中所有的容器，无论是否在运行。  此时可以看到，列表STATUS中多了其他状态 Exited(0) 6 months ago 代表：容器已退出(停止运行）退出时状态为 0 退出时间 6月前，同时我们看到PORTS中 0.0.0.0:32768->80/tcp 这代表两层含义 1:容器中开放了80端口，使用TCP协议，对应宿主机使用32768端口进行映射。此时可以使用"宿主机IP:32768" 对容器80端口提供的服务进行访问
  - -s：会列出容器的文件大小（容器增加的大小/容器的虚拟大小）；可以看到第一行的ubuntu镜像的容器的size列： SIZE：35.2MB（virtual 108MB）意思是容器在镜像ubuntu的大小的基础上增加了35.2MB，例如在容器中运行apt-get update 指令，会在写入层新增文件。 容器的虚拟大小=容器镜像的大小+容器增加大小
  - -q：仅列出CONTAINER ID 容器id字段（运行中的容器，加a列出所有容器的）。此命令常用于批量操作的参数，如批量停止所有容器 docker stop docker ps -a -q
  - -l: 显示最后一个运行的容器（无论该容器目前处于什么状态）
  - -n 数量x：显示最后 x 个运行容器，当x为1时和 -l 含义相同。(无论该容器目前处于什么状态）；常用于快速查找最近运行的容器
  - --no-trunc:不对输出进行截断操作，此时可以看到完整的COMMAND，CONTAINER ID
    高级指令：
  - -f : -filter 使用过滤器来过滤输出：例如：docker ps -f status=exited 过滤出状态为退出的； docker ps -f ancestor=597ce1600cf4 -f status=exited -a 过滤出父子镜像和状态为退出的





- docker exec -it 容器ID/容器名称 /bin/bash 进入容器内部,由于进入容器后需要与之交互，因此需要以-it为参数。exit退出容器。
- docker start/stop/restart 容器名称/ID 启动/停止/重启容器 
- docker rm 容器名称/ID 删除容器（除运行中的），加 -f 参数则进而强制删除运行中的。


- docker inspect 容器id  查看容器信息
