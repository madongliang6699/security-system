在 MySQL 中，`REGEXP`（或 `RLIKE`）用于匹配一个字符串是否符合给定的正则表达式模式。它比 `LIKE` 更加强大，可以用于复杂的模式匹配。

### 基本语法

```sql
SELECT column_name
FROM table_name
WHERE column_name REGEXP 'pattern';
```

### 例子

#### 1. **简单的字符匹配**
匹配所有以 "abc" 开头的记录：

```sql
SELECT *
FROM my_table
WHERE my_column REGEXP '^abc';
```

`^` 表示匹配字符串的开头。

#### 2. **匹配包含特定子字符串的记录**
匹配所有包含 "123" 的记录：

```sql
SELECT *
FROM my_table
WHERE my_column REGEXP '123';
```

#### 3. **匹配以特定字符结尾的记录**
匹配所有以 ".com" 结尾的记录：

```sql
SELECT *
FROM my_table
WHERE my_column REGEXP '.com$';
```

`$` 表示匹配字符串的结尾。

#### 4. **匹配一个字符集合**
匹配包含 "a"、"b" 或 "c" 中任何一个字符的记录：

```sql
SELECT *
FROM my_table
WHERE my_column REGEXP '[abc]';
```

#### 5. **匹配数字范围**
匹配包含任何数字（0-9）的记录：

```sql
SELECT *
FROM my_table
WHERE my_column REGEXP '[0-9]';
```

#### 6. **匹配字符串长度**
匹配所有长度为 4 的字符串：

```sql
SELECT *
FROM my_table
WHERE my_column REGEXP '^.{4}$';
```

`^` 和 `$` 限定整个字符串，`.` 表示任意字符，`{4}` 表示精确的字符数。

#### 7. **匹配多个模式**
匹配包含 "apple" 或 "orange" 的记录：

```sql
SELECT *
FROM my_table
WHERE my_column REGEXP 'apple|orange';
```

`|` 表示逻辑“或”操作。

### 常用的正则表达式模式

- `.` : 匹配任意单个字符。
- `*` : 匹配零个或多个前面的字符。
- `+` : 匹配一个或多个前面的字符。
- `?` : 匹配零个或一个前面的字符。
- `{n}` : 匹配前面的字符恰好 n 次。
- `{n,}` : 匹配前面的字符至少 n 次。
- `{n,m}` : 匹配前面的字符至少 n 次，至多 m 次。
- `[abc]` : 匹配方括号内的任意一个字符。
- `[^abc]` : 匹配不在方括号内的任意字符。
- `[a-z]` : 匹配方括号内的字符范围。
- `^` : 匹配字符串的开始。
- `$` : 匹配字符串的结束。

### 注意事项

1. **大小写敏感**：MySQL 中的正则表达式匹配默认是大小写敏感的。如果你想要进行不区分大小写的匹配，可以使用 `LOWER()` 或 `UPPER()` 函数。

   ```sql
   SELECT *
   FROM my_table
   WHERE LOWER(my_column) REGEXP 'pattern';
   ```

2. **转义字符**：在正则表达式中，某些字符具有特殊含义（如 `.`、`*`、`?` 等）。如果你想匹配这些字符本身，需要使用反斜杠 `\` 进行转义。

   ```sql
   SELECT *
   FROM my_table
   WHERE my_column REGEXP '\\.';
   ```

   上述查询匹配包含 "." 的字符串。

### 示例

假设我们有一个表 `employees`，其中有一个列 `email`，我们想要找到所有使用 Gmail、Yahoo 或者 Hotmail 的员工邮箱：

```sql
SELECT email
FROM employees
WHERE email REGEXP 'gmail|yahoo|hotmail';
```

这个查询会返回所有包含 "gmail"、"yahoo" 或 "hotmail" 的邮箱地址。

通过使用 `REGEXP`，你可以构建非常强大的搜索条件，适用于复杂的文本匹配需求。
