

## CentOS-1  
机器配置：2核2G，40G。  

安装了Jenkins：http://192.168.0.11:8080   账密：mdl / 123Mdl.

安装了docker：

集群方式安装了zk：客户端端口2181， 服务端口8081：http://192.168.0.11:8081/commands   
通过定时任务，间接配置了zk的开机自启动：每分钟启动一下zk：
~~~shell
[root@CentOS-2 app]# crontab -l
* * * * * /app/zookeeper/apache-zookeeper-3.6.2-bin/bin/zkServer.sh start >> /app/zookeeper/myCronTabStart.txt
~~~
